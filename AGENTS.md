# BattleCities project instructions

For every game UI task, read and follow `Assets/BattleCities/UI/AGENTS.md` before creating or editing screens, HUDs, buttons, or controls. It contains the user's approved fonts, text treatments, artwork handling, spacing, and Web/Seeker/PSG1 layouts. Apply these rules to UI code outside that directory as well.

Use these approved rules and the current implemented menu as the design reference when older descriptive documents disagree.
