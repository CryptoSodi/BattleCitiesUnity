# Approved game UI rules

These are the user's approved typography, layout, and interaction rules as of 2026-10-06. Apply them when creating or updating game pages, screens, menus, HUDs, and controls on Web, Seeker, and PSG1. Shop and tank selection are the current visual references. Later explicit user instructions take precedence.

## Creating future screens and pages

- Read this guide before designing or implementing a new UI, including UI code outside this directory. Reuse the existing artwork and shared helpers so future pages match the approved screens.
- Use Shop's title and bottom white status containers as the size and alignment reference. Put the title and its icon on the left, and navigation tabs or Back inside the title container on the right. Put the primary footer action inside the white bar, in the same slot as Connect Wallet and Continue.
- Fit the page content between those bars. A filter row nested inside a catalog keeps that catalog's width and position while sharing the title container's skin and height.
- Use the clean `15 SKR EACH` lettering wherever this guide calls for `PrizeAmount` or `ApplyCleanButton`. Those specific rules take precedence over the outlined white text fallback. Reapply the approved treatment after platform, selection, hover, and focus updates.
- Keep card activation, cursor hover, and controller focus distinct. Activation uses the original gold artwork; inactive cursor/controller focus uses the shared cyan outline and blue tint. Focus must reveal the complete card without activating it. Tabs use the full inactive blue button background for focus and the gold inset for the active tab.
- Keep platform font sizes and responsive fitting together. Enlarged PSG1/Seeker inventory text must remain readable and contained within all eight rows; returning to Web restores its original sizes.
- Inventory and Ranking's PAYOUTS sidebar share `TvSidebarStyle`: their white heading containers use the same fixed 42-unit height through `HeaderHeight`, with 3-unit top and side insets on every platform. Headings are 24 on Web and 32 on Seeker/PSG1; supporting text is 20 on Web and 28 on Seeker/PSG1, using the clean navy `PrizeAmount` treatment. Keep their header icons at the same visible scale with aspect fit. Compensate for the inventory crate's transparent margins so its illustration fills the header icon slot like the Payouts chest, without enlarging the sidebar or shrinking its item text.
- When the user approves a new reusable UI change, update this guide in the same task. Preserve the latest correction when it supersedes an earlier design choice.

## Fonts and text treatments

- Use the bundled Barlow Condensed family through `MenuTheme.HeadingFont`, `ArcadeTypography`, and the shared `ArcadeHeadingFont` TMP atlas. Use `BarlowCondensed-Bold.ttf`; Gold and WhiteButton treatments use the bold setting, while clean PrizeAmount and ApplyCleanButton lettering use Normal font style on that same bundled bold font.
- Golden yellow lettering uses the approved `ArcadeTextStyles` Gold treatment: a warm yellow-to-gold gradient, crisp dark brown outline, and short navy shadow. Apply this to golden titles, score values, fuel amounts, deployment cost, instruction titles (PLAY, REACH TOP 10, EARN SKR), and prize ranks (1ST, 2ND, 3RD, 4TH-10TH).
- For white labels without a specific clean-text rule below, use `ArcadeTextTreatment.WhiteButton`: a solid white face, crisp navy outline, and short dark shadow. Retain this fallback for HUD labels and values and other white display text. Tab, option, toggle, Back, action, and card-button captions always follow the clean rule below, as do leaderboard subtitles and inventory counts.
- All tabs, options, toggles, Back controls, blue/gold actions, and card buttons use `ApplyCleanButton` in every state: clean white on blue and clean navy on gold, with identical bundled BarlowCondensed-Bold font, Normal font style, size limits, alignment, and text bounds. Use zero face dilation, zero outline, and no shadow in both states. Only the caption color changes; never add Bold, outline, or shadow to inactive, focused, hovered, pressed, or disabled captions. Reapply this rule when building, changing selection, refreshing data, or restoring a platform layout. This includes Shop currencies/categories, Ranking scope/period options, Treasury, Field Manual, Socials, Settings, and every page's Back control; there is no outlined-blue-tab exception.
- Shop's SWAP tab and Ranking's TRADING tab are currently locked. Keep them visible with the shared gray locked skin, a silver padlock through `LockedTabIcon`, and clean white captions. Disable click/submit, skip them in controller navigation, and guard `SetCurrency(Swap)` / `SelectScope(true)` so direct calls cannot open their pages. Keep SKR, SOLANA, GAMING, and the gaming cycle/season picker available. Quarters' Trading card stays locked.
- Legacy uGUI uses `ArcadeTextStyles.ApplyGold` / `ArcadeGoldText`, `ApplyWhite` / `ArcadeWhiteText`, or `ApplyNavy`. TMP uses `ArcadeTextStyles.Apply`. Reuse the shared treatments and materials across platforms and interaction states.
- Main navigation labels (PLAY, SHOP, RANKING, QUARTERS, SOCIALS) use the clean prize amount lettering (15 SKR EACH): BarlowCondensed-Bold with FontStyle.Normal and no added outline or shadow. Use navy `(6,29,54)` on resting cream and active gold plates, and clean white on blue cursor/controller focus. Keep font, size, and alignment identical across these states. Preserve the larger caption sizes and raised placement below the icons, keep full labels on one line clear of the bottom rim, and reapply this treatment after restoring a platform layout.
- Inventory headings and item names, plus captions on gold button backgrounds, use that same clean prize amount lettering through `ArcadeTextTreatment.PrizeAmount`: the bundled bold font with Normal font style, navy `(6,29,54)`, zero face dilation, and no outline or shadow. Inventory count badges use the same clean treatment with a white face for contrast. Apply the clean navy caption whenever a button becomes gold through selection, focus, hover, or press; restore its approved white treatment on blue. For Continue, Connect Wallet, and card buttons, that white treatment is the same clean lettering through `ApplyCleanButton`.
- Shop card prices and tank card fuel buttons use the shared `ApplyCleanButton` lettering in both normal blue and active gold states. Preserve the same font, weight, sizing and alignment when selection changes; only the caption color changes from white to navy. Tank card LOCKED captions use the matching clean white lettering. Do not reapply the heavier WhiteButton treatment to these card captions during platform or selection refreshes.
- Use available space for readable text. Preserve alignment and responsive fitting; avoid wrapping or clipping compact headings and captions. TOP 10 EVERY 30 MINUTES has an enlarged text area and a maximum size of 28, with best fit on smaller layouts.
- Keep labels and related values close together. In particular, the fuel count belongs immediately after FUEL AVAILABLE.
- Keep the approved color values in `ArcadeTextStyles`: gold top `(255,235,112)`, gold bottom `(255,183,12)`, gold outline `(52,31,9)`, white outline `(6,33,64)`, navy face `(7,43,94)`, and shadow `(5,18,36,220)`.

## Buttons and artwork

- Reuse the established blue metal frames, gold selected states, cream panels, and supplied icons. Maintain the current illustrated game style across new screens.
- Page title icons match their main menu buttons. SHOP uses the shop/storefront navigation icon (`MenuTheme.NavigationIcons[2]`), and RANKING uses the ranking/podium navigation icon (`MenuTheme.NavigationIcons[3]`). Render them with aspect fit in the shared title icon slot.
- Shared title icons use a rectangle fitted to the sprite's aspect ratio and centered vertically in the header through `TvTitleHeaderLayout.PlaceTitle`. Move the entire icon/title group 8 units right of its original position to clear the left rim and bolts on every page. Keep an 8-unit gap from the icon slot to the title text. Shop and Settings cap icon height at 64% of the header height to clear the top rim; other title icons retain their existing 76% cap. Keep these insets and aspect fitting on every platform.
- Buttons with lettering baked into artwork must use aspect fit. For uGUI, use `Image.Type.Simple` with `preserveAspect = true`. Never stretch, squash, crop, or nine-slice artwork containing lettering.
- Separately rendered captions may sit over a sliced background when that artwork contains no text. Preserve the proportions of icons and text independently of the background.
- Apply the appropriate text and artwork treatment in normal, highlighted, selected, pressed, and disabled states. Extra layout space should become padding around artwork that must retain its proportions.
- Main navigation tracks the displayed page through `MainMenuScene.RefreshNavigationState`. Opening Shop activates SHOP's original gold plate and clears PLAY's gold page state; returning home restores PLAY. Navigation dialogs activate their corresponding item and Back restores the underlying page. Cursor hover and keyboard/controller selection of an inactive item use the dedicated blue menu plate through `MenuTheme.NavigationFocus` and `MenuButtonVisual`: `Art/reference-style-v2/shared/buttons/focus-blue.png`. This 1254 x 1254 transparent plate matches `inactive.png` and `active.png`, including their clipped corners, bevels, four silver bolts, and transparent margins. Render all three menu states as whole Simple images at the same tile dimensions; keep the blue menu asset separate from the sliced tab/button skins. Generation prompt, source references, and validation are recorded in `focus-blue.source.json`. Keep the active page gold while another item is focused. Resting inactive items retain their cream plate, and icons, tile dimensions, and caption positions stay unchanged. Refresh page state when screens open, close, or restore a platform layout; preserve the separate Start button behavior.
- Shop and tank cards share `CardSelectionHighlight` so cursor/controller focus is clearly visible. Hover/controller focus on an inactive card uses a cool blue body tint and a 3-unit cyan outline. Preserve activated cards' original gold frame, body color, and cost button; do not add a gold tint or extra gold outline. Keep focus effects on the inactive card background only, leaving text and illustrations clear, and retain the existing card sizes, scrolling, and click/submit behavior.
- Select Tank fuel and locked buttons span 80% of the card width, centered between the lower inside corners. Keep their existing height, calculated from 72% of card width and the original active-blue sprite aspect ratio with a 1.25 height multiplier. Leave a bottom inset of 2.3% of card width so the button sits inside the rim.
- Play tank cards use a width-to-height ratio of 0.85. Preserve the established tank artwork and title sizes relative to card width, and remove spare height below the four stat rows. Keep a small clear gap above the fuel button; PSG1 uses tighter stat-row spacing with the approved readable lettering.
- Fuel-button skins contain no text and use slicing to preserve their rounded corners at the original width-based scale. The three supplied skins have 128-pixel borders. Keep the fuel icon and caption grouped and centered, with clearance from the stat rows and card rim.
- Continue uses the same empty blue skin as the fuel buttons, with a gold skin for focus, hover, and press. Both states use identical clean `PrizeAmount` lettering: bundled BarlowCondensed-Bold with Normal font style, zero face dilation, and no outline or shadow. Only the caption color changes: white on blue and navy on gold. Keep the caption centered at the same size across states. Tank selection's white footer bar spans the available width and contains Continue in the shared Shop footer action slot through `TvStatusFooterLayout.PlaceAction`. Match Connect Wallet's position and dimensions: 22% of the bar width, 78% of its height, vertically centered, with a 1.5% right inset. Preserve the rounded corners and keep fuel and deployment details to its left without overlap.
- Tank selector illustrations fit within a centered area 72% of the card width and 42.75% of its width in height, keeping their original proportions and a little space below the name and above the stats. Position them slightly lower in that area of the card and use a soft oval contact shadow below their tracks, rendered behind the artwork.
- Leaderboard trophies use matching soft oval contact shadows behind their bases, scaled to the fitted artwork. Hide the empty-state trophy's shadow whenever that trophy is hidden.
- Future cards with featured object illustrations must include the same soft oval contact shadows beneath the objects. Reuse the shared `TankGroundShadow` graphic with the approved warm dark color `(35,25,13,112)` and soft fading edges. Center each shadow under the object's base and size it to the fitted artwork's footprint. Render it behind the artwork, keep it clear of labels and the card rim, disable raycasts, and show or hide it together with the object. Preserve this treatment on Web, Seeker, and PSG1.

## TV layout and spacing

- Web and Seeker landscape use navigation on the left, the TV in the middle, and the leaderboard on the right. Landscape detection must work in both the Unity Editor and runtime.
- Preserve PSG1's approved platform composition and controller navigation. Its controller key details disappear, after which HOW IT WORKS appears inside the TV.
- On Seeker landscape and PSG1, place the HUD inside the TV. Keep Commander and Hi-score cards compact, with icons, progress, and the level pill aligned as in the web reference. Avoid excessive blank width and oversized score readouts.
- TV content on Web, Seeker landscape, and PSG1 fills `TV Background Viewport` with a modest 12-unit clearance from its rim. Use small fixed inner margins and let the roster or loadout fill the space between the header and footer. Do not add the TV sprite's full sliced border or percentage-based outer padding to the visible opening.
- Use available TV space while retaining a little breathing room around content. Avoid both unused outer space and a crowded arrangement.
- Shop defines the canonical title and bottom white container dimensions for all future screen UIs. Reuse `TvTitleHeaderLayout` for the title and `TvStatusFooterLayout` for the white footer on every platform. Both span the screen content width minus 8 units, with 4-unit side insets. The title height is `Clamp(contentHeight * 0.083, 46, 64)`, placed 4 units from the top; the white footer height is `Clamp(contentHeight * 0.078, 50, 64)`, placed 4 units from the bottom. Preserve the Shop skins and their sliced scales: title 4, white status bar 3. Keep actions inside the bars and let screen content fit between them. Use these shared sizes rather than separate tank, platform, or new-screen height overrides.
- Footer actions also reuse `TvStatusFooterLayout.PlaceAction` on every platform. Continue, Connect Wallet, and future footer actions occupy the same rightmost slot: left edge at 76.5% of bar width, width 22%, height 78%, vertically centered with 11% top/bottom padding and a 1.5% right inset. Reserve the area to their left for status content, with a clear gap.
- Tank selection uses the same full-width title container and shared `TvTitleHeaderLayout` sizing as Shop. Align the existing tank icon and gold SELECT TANK title on the left, with the Back control inside the container on the right. Match Shop's title and Back caption size, icon bounds, white arrow, compact Back dimensions, tighter corners, and focus marker. Allow enough title width for SELECT TANK and BATTLE LOADOUT without shrinking or wrapping their lettering.

- Fresh game launches show the main Home screen. Clear saved Editor page previews during runtime startup so Select Tank, Loadout, Shop, Settings, and other pages only open through navigation. Preserve explicit incoming player-profile links.
